# 女频短篇古言爽文 · 爆款流水线公式

> 来源：19 篇拆文分析大数据提炼（播放量 0–7637）
> 用途：配合 `/story-female-revenge-write` 使用，负责选题、粗纲、细纲阶段

---

## 一、开篇钩子（必选1种）

| 类型 | 经典场景 | 杀伤力 |
|------|---------|--------|
| **肉体羞辱型** | 交杯酒里下绝子药、安胎药被换成堕胎药、当街罚站两个时辰 | ★★★★★ |
| **身份剥夺型** | 当众夺诰命、废后位、贬为侧妃、抢嫁妆、毁名声 | ★★★★☆ |
| **情感背叛型** | 新婚夜喊别人名字、为妾室罚正妻、放妻书递来时她正绣战袍 | ★★★★★ |
| **骨肉分离型** | 带球跑被抓回、孩子被抢、为保胎被强灌药 | ★★★★☆ |

> **法则**：钩子必须涉及女性核心焦虑——**生育权、身体自主、尊严底线**。越具体、越视觉化，转化率越高。

---

## 二、女主硬技能（必选1–2种）

| 技能 | 变现路径 | 爽点场景 |
|------|---------|---------|
| **医术** | 开医馆、入太医院、专治妇科暗疾 | 前夫/新欢辗转求到她门前排队 |
| **刺绣** | 双面绣、缂丝、入宫奉召、开绣庄 | 宫宴上她的作品碾压全场 |
| **武力** | 女将军、暗器、战场、护卫镖局 | 前夫被绑架时她去救 |
| **经商** | 茶楼、酒楼、绣坊、盐运、钱庄 | 前夫来她的店消费却不知东家是谁 |
| **厨艺** | 私房菜、药膳、宴席设计 | 用菜名影射前夫罪行 |
| **琴棋书画** | 入宫为师、名流雅集、开书院 | 太后/皇帝亲自点名要她作品 |

> **法则**：「被抛弃」只赚同情，「被抛弃后我靠 X 手艺月入千两」才赚爽感。

## 三、男主类型（必选1种）

| 类型 | 特征 | 适用结局 |
|------|------|---------|
| **追妻火葬场型** | 前夫/前未婚夫，后悔莫及，付出真实代价 | BE 或开放式；若要 HE 须革职/天牢 |
| **新欢救赎型** | 从一开始就尊重她、欣赏她的才华 | HE |
| **侧面守候型** | 默默帮助、后期才确认关系 | HE 或开放式 |
| **无 CP 型** | 女主独美，不回头，事业封顶 | BE / 开放式（近年高播放量趋势） |

## 四、情绪节奏（黄金比例）

```
起 15-20% → 承 20-25% → 转1 15-20% → 转2 15-20% → 合 20-25%
```

| 段 | 情绪 | 必须完成 |
|---|---|---|
| **起** | 冰冷绝望 | 钩子落地，女主反应立人设 |
| **承** | 沉静蓄力 | 离开、技能变现、建立新秩序 |
| **转1** | 温暖希望 | 新男主登场 / 事业高峰，给口气喘 |
| **转2** | 紧张危急 | 前夫捣乱 / 阴谋揭露，推上高峰 |
| **合** | 释然爽感 | 打脸报应 + 女主选择 + 画面定格 |

## 五、快速选题生成器

```
【钩子】 + 【女主技能】 + 【变现路径】 + 【结局类型】 = 选题
```

**范例组合**：
- `绝子药` + `医术/妇科` + `开医馆` + `不回头` = 《麝香帐》
- `百子帐赏给新欢` + `缂丝/藏暗纹` + `入尚功局` + `终生未嫁` = 《裂帛书》
- `递休书时绣战袍` + `厨艺` + `开酒楼` + `HE嫁御史` = 《休夫宴》

## 六、爽点武器库（至少用2个）

1. **前夫排队求诊**：她的店前夫不得不来，还得按规矩排队递名帖
2. **当众打脸**：宫宴/雅集上，她的作品碾压新欢/前夫现任
3. **藏证据于技艺**：绣品藏暗纹、菜品藏密语——技艺即武器
4. **以死相逼**：她用刀指著自己（而非前夫），逼他放人/认罪
5. **孩子认母**：带球跑中，孩子当著前夫面只认她
6. **身份反转**：弃妇实为郡主/公主/世家失散千金
7. **太后/皇帝撑腰**：高位者亲自站台，前夫连跪的资格都没有

## 七、结局决策树

```
目标播放量 > 5000？
  ├─ 是 → 建议 BE 或开放式（女主过得好，男主后悔但无法挽回）
  └─ 否 → 目标播放量 > 1000？
           ├─ 是 → HE，女主独立事业 + 感情双丰收
           └─ 否 → 尝试 BE/开放式，测试市场反应
```
