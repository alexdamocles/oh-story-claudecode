# 女频复仇爽文结构总表

> **用途**：女频复仇爽文的结构总表。拆文和写大纲时对照使用；题材方向须先由用户、对标书或专门选题资料确定。本文件只负责在既定方向下校准结构比例、事件节拍与情绪落点。

## 固定结构总表（开书必读）

> **使用边界**：本节只统一约 4.2 万字女频复仇故事的结构骨架，**不负责题材选择或选题组合**。题材方向由用户要求、已有对标书或专门的选题资料决定；需要背叛素材、反杀变体和结局细节时，再按需回读对应参考文件。

### 五段式与字数预算

| 阶段 | 默认节次 | 占比 / 字数 | 结构任务 |
|---|---|---:|---|
| 伤害 | 1-2 节 | 10%，4,000-4,500 字 | 钩子当场落地，具体伤害与代价显形。 |
| 隐忍 | 3-6 节 | 20%，8,000-9,000 字 | 表面承受，暗中盘点资源、埋线索、准备退路。 |
| 反杀 | 7-12 节 | 30%，12,000-13,500 字 | 女主做出公开或不可逆行动，并承受第一轮反制。 |
| 新秩序攻防 | 13-18 节 | 30%，12,000-13,500 字 | 建立立足点，经历反扑、损失、调整与最终清算。 |
| 火葬场 / 收束 | 19-20 节 | 10%，4,000-4,500 字 | 对手后果兑现，女主以不可逆的新生活落幕。 |

### 双发动机与 20 节骨架

全文必须同时推进两条因果相连的线：**关系断裂**（伤害 → 确认真相 → 控制局面 → 不可逆选择）与**新秩序攻防**（取得立足点 → 遭遇阻碍 → 小胜与代价 → 反制升级 → 公开清算）。后者必须从前段已铺垫的能力、资源、关系或选择自然生长，不能凭空掉落身份、财富或强援。

20 节应是 5-7 个主要事件经由“准备 → 行动 → 反制 → 代价 → 结果”形成的连续状态变化，而不是 20 件互不相干的事：

| 节次 | 必须完成的状态变化 |
|---|---|
| 1-2 | 伤害发生、真相确认；女主先控制第一处风险。 |
| 3-6 | 盘点资源与后果，试探规则，转移关键资源，确定不可回头目标。 |
| 7-10 | 执行第一项公开 / 不可逆行动；对手反制；女主获得助力但只赢一部分。 |
| 11-12 | 对手升级，击中女主脆弱资源；女主付出重大损失，旧秩序正式断裂。 |
| 13-16 | 女主建立新身份、事业或权力立足点，受现实规则阻碍后拿到可见成果；关键关系或证据再度翻转。 |
| 17-18 | 对手最后反扑；女主公开底牌并完成清算，使新秩序稳定。 |
| 19-20 | 对手理解失去却无法挽回；女主继续生活的具体画面定格主题。 |

不得删掉“对手反制、女主重大损失、新秩序受阻”三类节点；双线只在产生新结果时切换，时间跳跃只能兑现已完成的因果，不能跳过因果。

### 开篇钩子

首个自然段直接给出强冲突、强反常、强信息差或强代价之一；前 100 字先炸点后解释，前 2,000 字完成伤害事件、女主的动作性反应、贯穿道具、对手破绽与旁人反应。钩子应具体、可视、触及身体自主、尊严或生存底线；女主可以痛，但第一反应必须是控制局面，而不是只哭或只想。

### 反杀升级与结局决策

反杀不是“决定离开”，而是已经完成一个不可逆动作。每次核心反杀都要同时具备：

1. **动作**：搬、签、走、夺、公开证据等可见行动；
2. **速度**：低烈度冲突可当场或次日兑现，高烈度长线布局必须展开对手反制、女主代价和新秩序攻防；
3. **结果**：和离不复婚、离开不折返、权力或资源归属发生不可逆改变。

反杀后必须给出“对手得知冲击 → 追赶或反制 → 女主不回头的定格画面”这一组兑现镜头。结局则按“他知道了 → 他追 / 找但追不上 → 彻底失去希望”完成对手账单；代价应来自女主的选择或布局，不靠运气代偿。最后用女主已建立的新生活、身份或秩序收束，而不是用原关系复合抹掉前文代价。

## 追妻火葬场

### 8 个宏观节点（映射到 20 节）

**设定**：女主被伤害 → 离开 → 男主后悔追回但女主不回头。场景：古代贵族\民国，需权力差。

**人物**
| 角色 | 弧线 |
|------|------|
| 女主 | 隐忍付出 → 心死离开 → 独立成功 → 掌控主动权 |
| 男主 | 高冷傲慢 → 后期卑微追悔，痛点要"活该但又心疼" |
| 第二男主(选配) | 温柔守候，制造男主危机感+读者情感出口 |

**8 个宏观节点**：用于检查宏观情绪与事件功能；实际落到 Phase 3 的 20 节大纲时，必须保留五段式、对手反制、女主重大损失和新秩序受阻等硬节点。
| 节点 | 内容 | 占比 | 情绪 |
|------|------|------|------|
| 1.开篇钩子 | 展示女主痛苦现状 | 5% | 压抑 |
| 2.虐待加深 | 冷漠/背叛达顶点 | 10% | 悲愤 |
| 3.女主觉醒 | 决定离开 | 10% | 痛→决绝 |
| 4.离开与新生 | 独立生活/事业 | 15% | 爽(解脱) |
| 5.男主追悔 | 意识女主重要性 | 10% | 痛快 |
| 6.事业/成长 | 新领域取得成绩 | 15% | 爽(逆袭) |
| 7.反复拉扯 | 多次求复合被拒 | 20% | 爽(打脸) |
| 8.结局 | 开放/回头/悲剧 | 15% | 释放 |


## 重生复仇

### 8 个宏观节点（映射到 20 节）

**设定**：前世惨死→重生利用信息差逐一复仇。场景：宅斗/宫斗/商战/校园，需复杂人际网。

**人物**
| 角色 | 要点 |
|------|------|
| 女主 | 前世天真→重生腹黑，金手指=前世记忆，核心矛盾=是否变成仇人一样的人 |
| 反派层 | 小(3-10章)→中(20-50章)→大(全书)，层级嵌套 |
| 盟友/男主 | 前世可能被误解，逐步信任，制造信任危机 |

**8 个宏观节点**：用于检查宏观情绪与事件功能；实际落到 Phase 3 的 20 节大纲时，必须保留五段式、对手反制、女主重大损失和新秩序受阻等硬节点。
| 节点 | 内容 | 占比 | 情绪 |
|------|------|------|------|
| 1.冲突揭露 | 前世惨死真相 | 5% | 震惊/愤怒 |
| 2.重生认知 | 梳理记忆定目标 | 5% | 期待 |
| 3.前世今生交织 | 对比被蒙蔽vs清醒 | 15% | 爽(信息差碾压) |
| 4.逐层复仇+新问题 | 打小反派揭大阴谋 | 25% | 爽→悬念交替 |
| 5.多重阻碍 | 中反扑+信任危机 | 15% | 紧张 |
| 6.高潮致命一击 | 终极布局对决 | 15% | 爽(最高潮) |
| 7.反派下场 | 逐一报应 | 10% | 爽(宣泄) |
| 8.新生活 | 选择新方向 | 10% | 治愈/释然 |

## 通用拆文提醒

| 检查项 | 说明 |
|--------|------|
| 结构识别 | 既定题材所用的结构模板是否明确？有无不必要的结构混搭？ |
| 节奏比例 | 五段式、20 节预算与 8 个宏观节点是否一致？ |
| 反转位置 | 在百分之多少出现？ |
| 钩子密度 | 每 1-2 节至少一个明确悬念、反转或信息差钩子？ |
| 字数效率 | 有无废段落？哪些可删？ |
| 情绪落点 | 读完最后一句是什么感觉？ |

## 质量检查清单

每次使用本手册完成拆文或大纲后，逐项核对：

| # | 检查项 | 通过标准 |
|---|--------|----------|
| 1 | **结构模板明确** | 已按既定题材选定对应结构模板，无模棱两可 |
| 2 | **结构比例达标** | 五段式和 20 节预算完整；8 个宏观节点均已映射到对应节次 |
| 3 | **情绪节拍完整** | 压抑→爆发→释放的完整情绪弧线存在，无断层 |
| 4 | **人物弧线明确** | 主角有清晰的起点和终点变化；反派有独立动机不是工具人 |
| 5 | **钩子密度足够** | 每 1-2 节至少一个悬念/反转/信息差钩子 |
| 7 | **信息差利用到位** | 有读者知道但角色不知道、或角色知道但对手不知道的信息差设计 |
| 8 | **技法匹配题材** | 已对照对应题材的"技法"条目，无遗漏 |
| 9 | **无废段落** | 每段都推进情节或深化人物，无纯填充 |
| 10 | **结局情绪对位** | 结尾情绪与题材核心匹配（爽文=释放/治愈；虐文=意难平/余韵） |
