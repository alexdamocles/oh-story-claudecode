## 3. 可模仿的创作习惯

### 3.1 先给伤害，再补关系债

开场先落一个已经发生的具体伤害：下毒、休妻、贬妻、外室、夺功、送入死地。人物身份、婚姻历史和旧日承诺只补充“为什么这一刀疼”，不能先讲完背景再发生冲突。

### 3.2 女主第一反应是控制局面

女主可以痛，但不能只痛。得知伤害后的第一组动作通常是换药、查账、转移嫁妆、联系旧部、准备文书、隐藏孩子或安排退路。情绪通过动作和选择显现。

### 3.3 反杀动作出现得早，结算出现得晚

离开、和离、假死、搬空财产不是全文高潮，而是故事换挡点。它先切断旧秩序，再打开第二发动机。最终爽点来自这个选择经过多轮阻挠后仍然成立，并让对手承担不可逆后果。

### 3.4 用“办成具体事情”证明成长

语料习惯用可见过程证明能力：核账、调人、运货、找证人、救急、争取支持、处理官府、掌兵、稳定局势。每次办事必须改变资源或权力状态，不能连续写同类障碍只为增加篇幅。

### 3.5 新秩序必须遭到反扑

女主离开后不能一路顺风。至少出现三次不同层级的阻力：

1. 旧关系追查或情感拉扯。
2. 现实资源、名誉、身份或生存阻碍。
3. 对手利用权力、规则或第三方发动反制。

女主至少付出一次真实代价，例如失去盟友、暴露底牌、损失资产、被迫转移、名誉受损或计划延期。

### 3.6 双线只在产生新结果时切换

可在女主行动线和对手反应线之间切换，但每次切换必须带来新信息、新行动或新代价。单纯重复“他后悔、他寻找、他喝酒”不算推进。

### 3.7 时间跳跃用于兑现，不用于跳过因果

“三个月后”“三年后”适合展示事业、孩子、身份和关系结果。关键选择、重大损失和反制过程必须写出来，不能靠时间跳跃代替。

### 3.8 结尾用不可逆状态收束

结尾不是口头宣言，而是新状态：新身份成立、事业可持续、孩子安全、旧关系无法恢复、对手失去权力或永久错过。最后一个画面应让读者看见女主正在继续生活。

## 4. 4.2 万字的双发动机

只靠“背叛 -> 离开 -> 后悔”通常只够较短篇幅。默认故事必须同时具备两个发动机：

### 发动机 A：关系断裂

```text
具体伤害 -> 确认真相 -> 控制局面 -> 准备退路 -> 做出不可逆选择
```

### 发动机 B：新秩序攻防

```text
取得立足点 -> 遇到现实阻碍 -> 第一次小胜 -> 旧势力反制
-> 女主付出代价 -> 调整策略 -> 公开反转/清算 -> 新秩序成立
```

两个发动机必须因果相连。女主的新事业、军权、身份或盟友必须源于前段已经建立的技能、资源、关系或选择；禁止中段凭空掉落更强男主、圣旨、巨额财富或隐藏身份解决问题。

## 5. 20 节事件骨架

20 节不是 20 个互不相关的大事件，而是 5-7 个主要事件经过准备、行动、反制、代价和结果形成的 20 次状态变化。

| 节 | 必须完成的结构任务 |
|---:|---|
| 1 | 伤害当场发生，具体代价显形 |
| 2 | 女主确认伤害不是误会，并控制第一处风险 |
| 3 | 盘点可用资源、限制和失败后果 |
| 4 | 试探对手或规则，获得第一条有效信息 |
| 5 | 转移第一项关键资源，留下可回查痕迹 |
| 6 | 对手施压，女主确定不可回头的目标 |
| 7 | 女主执行第一次公开或不可逆行动 |
| 8 | 对手发现变化并发动第一次反制 |
| 9 | 女主获得盟友或工具，同时支付交换代价 |
| 10 | 第一轮正面对抗，女主只赢一部分 |
| 11 | 对手升级手段，攻击女主最脆弱的资源 |
| 12 | 女主遭受重大损失，旧秩序正式断裂 |
| 13 | 女主建立新身份、事业或权力立足点 |
| 14 | 新秩序遭遇现实规则或地方势力阻碍 |
| 15 | 女主用已铺垫的能力解决问题，取得可见成果 |
| 16 | 盟友立场变化或关键证据反转，局势再次失衡 |
| 17 | 对手最后反扑，逼女主公开底牌或承担代价 |
| 18 | 女主完成最终清算，新秩序获得合法性/稳定性 |
| 19 | 对手后果兑现，理解自己失去什么但无法挽回 |
| 20 | 女主继续生活的具体画面，主题落地 |

允许按题材调整节号，但不得删掉“对手反制、女主重大损失、新秩序受阻”三类节点。否则中段会退化为连续亮底牌。

## 6. `设定.md` 必须提供的结构信息

### 故事发动机

- 女主外部目标、不能失败的原因、时间压力、最坏失败结果。
- 对手目标、双方零和冲突、对手为何不能放女主离开。
- 关系断裂发动机和新秩序发动机分别是什么，两者如何因果连接。

### 资源与限制

- 女主初始资源、隐藏资源、尚未获得的关键资源。
- 每项强资源的来源、使用条件和代价。
- 对手掌握的权力、人脉、信息优势和致命盲点。

### 对抗升级链

- 初始伤害、女主试探、第一次反制、第一次小胜、升级伤害、重大损失、最终反扑和最终清算。
- 每一轮必须写清“谁主动做什么 -> 对方如何回应 -> 谁付出什么 -> 状态如何改变”。

### 配角与证据

- 配角必须有自身目标、掌握资源、初始立场和转变原因。
- 线索必须记录首次出现、错误解释、再次出现和最终用途。
- 新出现的人或资源不得只在解决问题的那一刻才进入故事。

## 7. 大纲验收

每节大纲除主事件和情绪外，必须回答：

1. 女主本节做了什么主动选择？
2. 谁或什么规则阻止她？
3. 她为结果付出了什么代价？
4. 本节结束后，资源、权力、证据、名誉、身份、关系、目标或风险至少哪一项发生变化？
5. 这个变化如何迫使下一节发生？

连续两节没有外部阻力，或连续两节只有情绪变化而没有状态变化，必须重写大纲。连续使用同一种阻碍或同一种解决办法，也必须更换冲突层级。

## 8. 模仿边界

- 可以模仿：高冲突开场、冷静行动、早断裂晚结算、程序性能力展示、双线反应、新秩序反扑、不可逆结尾。
- 不可复制：原文句子、角色姓名、标题句式的完整组合、特定道具组合、完整事件顺序和独有反转。
- ASR 文本不可作为措辞和标点示范；正文语言仍以 `format-and-structure.md`、`anti-ai-writing.md` 和当前题材文风约束为准。
